# 新規作成ゲート (Creation Gate)

> **新しいファイル・フォルダ・機能を作る前に必ずこのチェックを通過すること。**  
> 通過しない限り作成してはいけない。

---

## ゲートチェックリスト

### 1. 必要性の確認

- [ ] なぜ作る必要があるか、一文で言える
- [ ] 今なくて困っていることが具体的に言える
- [ ] `next-actions.md` に記載されているアクションに紐づいている

### 2. 代替案の確認

- [ ] 既存のファイルで代用できないか確認した
- [ ] `idea-parking-lot.md` に似たものがないか確認した
- [ ] `rejected-ideas.md` に過去に却下された類似案がないか確認した

### 3. スコープの確認

- [ ] `agenda.md` の「今回決めたいこと」に含まれている
- [ ] 既存プロジェクトへの影響がない
- [ ] APIキー・外部連携・Web UI実装ではない

### 4. 管理コストの確認

- [ ] 作ったあとに誰が（どのAIが）管理するか決まっている
- [ ] 増える管理対象ファイルを書き出した: 
- [ ] 週次レビューで見るべき対象に追加できる

### 5. 保存場所の確認

- [ ] `ai-meeting-hub/` 内に収まる
- [ ] 既存フォルダ・ファイルを移動・改名しない
- [ ] ファイル名が `decision-id-rule.md` のルールに沿っている（必要なら）

## ゲート通過後の手順

1. `decision-log.md` に「〇〇を作ることを決定」を記録する
2. `next-actions.md` に作業を追加する
3. 作成後に `work-report-template.md` で報告する
4. `auditor-check.md` で監査を通過させる
