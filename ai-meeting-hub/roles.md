# 役割定義 (Roles)

> 更新日: YYYY-MM-DD

---

## 役割一覧

| 役割 | 担当AI / 担当者 | 主な責任 |
|---|---|---|
| 議長 | | 議論を進行し、脱線を防ぐ |
| 設計者 | | アーキテクチャ・構成を決定する |
| 実行者 | | コード・ファイルを実際に作成・変更する |
| 調査者 | | 情報収集・調査・比較を行う |
| 監査役 | | 決定・実装が方針に沿っているか確認する |
| 記録係 | | 会議ログ・決定ログを記録する |

---

## 各役割の詳細

### 議長

**責任:**
- 議題から外れた議論を止める
- 時間内に決定に導く
- 対立意見を整理して統合判断を促す

**禁止事項:**
- 自分の意見を押し通す
- 決定を先延ばしにし続ける

**AI担当時の指示例:**
```
あなたは議長です。以下の議題について議論を進めてください。
脱線した場合は「スコープ外です」と明示してください。
[agenda.mdの内容を貼る]
```

---

### 設計者

**責任:**
- 実装方針・ファイル構成を決める
- トレードオフを明示する
- 「やること / やらないこと」を区別する

**禁止事項:**
- 過剰設計（今必要ないものを作る）
- 曖昧なまま実行者に渡す

**AI担当時の指示例:**
```
あなたは設計者です。以下の要件に対して実装方針を提案してください。
「やること / やらないこと」を明示してください。
[agenda.mdの内容を貼る]
```

---

### 実行者

**責任:**
- 設計者の決定に従ってコード・ファイルを作成する
- 既存プロジェクトへの変更は行わない（明示的な指示がない限り）
- 完了後に `work-report-template.md` で報告する

**禁止事項:**
- 設計にない機能の追加
- 既存ファイルの無断変更

**AI担当時の指示例:**
```
あなたは実行者です。以下の設計に従ってファイルを作成してください。
設計にない実装は行わないでください。
[decision-log.mdの関連決定を貼る]
```

---

### 調査者

**責任:**
- 技術的選択肢を調査・比較する
- 公式ドキュメント・信頼できる情報源を参照する
- 調査結果をまとめて設計者に渡す

**禁止事項:**
- 調査結果を決定として扱う（決定は設計者の役割）

---

### 監査役

**責任:**
- 実装が `definition-of-done.md` の条件を満たしているか確認する
- `auditor-check.md` のチェックリストを使う
- 問題があれば実行者にフィードバックする

**禁止事項:**
- 実装を自分で修正する（監査と実装の混在を防ぐ）

---

### 記録係

**責任:**
- 会議ログを `meeting-log.md` に記録する
- 決定を `decision-log.md` に転記する
- 次アクションを `next-actions.md` に追記する

---

## ロールの切り替えルール

- 1つのAIが複数役割を担当してよい
- ただし「監査役」は他の役割と**分離する**ことを推奨
- セッションが変わるときは `handoff-template.md` を使って引き継ぐ
