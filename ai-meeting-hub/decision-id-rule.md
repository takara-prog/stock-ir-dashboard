# 決定ID命名規則 (Decision ID Rule)

---

## 形式

```
DEC-YYYY-MMDD-連番
```

| 部分 | 説明 | 例 |
|---|---|---|
| `DEC` | 決定 (Decision) の固定プレフィックス | `DEC` |
| `YYYY` | 西暦4桁 | `2025` |
| `MMDD` | 月日4桁（ゼロ埋め） | `0615` |
| `連番` | その日の決定の通し番号（3桁ゼロ埋め） | `001` |

**例:** `DEC-2025-0615-001`

---

## ルール

1. **変更禁止**: 一度発行したIDは変えない（決定を無効にしても番号は残す）
2. **欠番OK**: 却下・無効になっても番号は詰めない
3. **ステータス管理**: 無効になった決定は `decision-log.md` でステータスを「無効」に変更
4. **再評価**: 同じ内容を再決定する場合は新しいIDを発行し、旧IDを「無効」にする

---

## 関連IDの種類

| 種類 | プレフィックス | 例 |
|---|---|---|
| 決定 | `DEC` | `DEC-2025-0615-001` |
| 会議 | `MTG` | `MTG-2025-0615-001` |
| アクション | `ACT` | `ACT-2025-0615-001` |

## よくある間違い

| 間違い | 正しい形式 |
|---|---|
| `DEC-2025-6-15-1` | `DEC-2025-0615-001` |
| `DEC20250615001` | `DEC-2025-0615-001` |
| `decision-001` | `DEC-2025-0615-001` |
